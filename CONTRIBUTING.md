# Contributing

Bug reports and focused pull requests are welcome.

1. Fork and clone the repository.
2. Install Node.js 22 or newer and pnpm 11.
3. Run `pnpm install --config.blockExoticSubdeps=false`.
4. Make the change and add or update tests.
5. Run `pnpm test` before opening a pull request.

Please do not submit proprietary Kontakt libraries, copyrighted library artwork, registry-bypass features, activation workarounds, or tools intended to circumvent Native Instruments licensing.
